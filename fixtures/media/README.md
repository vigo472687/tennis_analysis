# Synthetic media fixtures

The source of each generated asset is generate.mjs, maintained in this project for local tests. No personal video or licensed player footage is included. Geometry is a simple drawn figure, not captured tennis or inferred body keypoints. Device labels describe simulated input scenarios, not real camera captures or compatibility proof.

```sh
node fixtures/media/generate.mjs --out /tmp/tennis-fixtures
node fixtures/media/generate.mjs --out /tmp/tennis-fixtures-small --ids iphone-flat,missing-feet,damaged
```

The generator runs local FFmpeg with argument arrays, bounded duration and a timeout. It creates MP4, evidence PNG and an iPhone-scenario MOV remux in the selected output directory. generated.json records sizes and hashes. The damaged fixture intentionally contains invalid bytes. Native-panorama and mirror cases are declared fixture metadata; these clips do not prove real projection or camera-direction detection.

Assets are project-generated local test fixtures, not a third-party training dataset. No external model download or publication permission is implied. Generated bytes remain in test/output directories and are not source changes. The immutable source manifest identifies the fixture/configuration version. Actual test evidence must record the local FFmpeg version and never report synthetic outcomes as model accuracy.
